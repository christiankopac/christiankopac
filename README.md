## What I'm working on

I'm a software engineer at Dewesoft Monitoring, building real-time sensor monitoring web apps for construction projects (Preact), plus a desktop app for device configuration (Rust, Tauri, Preact).

On the side, a few smaller fun projects:

- 🫟 [**Apacible Hugo Theme**](https://github.com/christiankopac/apacible-hugo-theme)\
  A minimalist Hugo theme built for simplicity and speed. Great for personal blogs and portfolios.

- 🫆 [**Typst Multilingual Resume and Cover Letter Template**](https://github.com/christiankopac/typst-resume-and-cover-letter-template)\
  A clean, professional Typst template for writing resumes and cover letters in multiple languages.

- 🪉 [**Obsidian Audiobookshelf Plugin**](https://github.com/christiankopac/obsidian-audiobookshelf-plugin)\
  Integrates [Obsidian](https://obsidian.md) with Audiobookshelf, so you can manage and access your audiobooks right inside your vault.

- 🪏 [**Obsidian KOReader Plugin**](https://github.com/christiankopac/obsidian-koreader-plugin)\
  Syncs highlights and bookmarks from KOReader devices into [Obsidian](https://obsidian.md), with custom templates and smart organization.

- 🫩 **Emacs**\
  My ever-evolving Emacs configuration, tuned for my workflow. Did someone say org-mode 🤩
