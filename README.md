## What I'm working on lately

Currently working as software engineer @ Dewesoft Monitoring - building amazing monitoring web apps for realtime sensors for construction monitoring applicaitons (Preact) as well as a desktop app for configuraiton of devices (Rust, Tauri, Preact).

Otherwise working on some smaller fun side projects:

- 🎨 [**Apacible Hugo Theme**](https://github.com/christiankopac/apacible-hugo-theme)
  A minimalist and elegant Hugo theme designed for simplicity and speed. Perfect for creating personal blogs or portfolio sites.

- 🏢 [**Typst Multilanguage Resume and Cover Letter Template**](https://github.com/christiankopac/typst-resume-and-cover-letter-template)
  A clean and professional Typst template to help you craft resumes and cover letters in multiple languages.

- 🎧 [**Obsidian Audiobookshelf Plugin**](https://github.com/christiankopac/obsidian-audiobookshelf-plugin)
  A plugin for [Obsidian](https://obsidian.md) that integrates with Audiobookshelf, giving you the ability to manage and access your audiobooks directly within Obsidian.

- 🔖 [**Obsidian Koreader Plugin**](https://github.com/christiankopac/obsidian-koreader-plugin)
  A plugin for [Obsidian](https://obsidian.md) that syncs highlights and bookmarks from KOReader devices with custom templates and smart organization.

- 🧑💻 Enmacs 
  A continuously evolving Emacs configuration aimed at optimizing my workflow with powerful, customizable tools and features. Somebody said org-mode?!
